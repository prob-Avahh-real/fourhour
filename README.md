# FourHour

A daily productivity app based on the "4-hour work day" philosophy, helping users focus on deep work and track their time budget.

## Features
- 4-hour daily deep work budget tracker
- Eisenhower matrix task prioritization
- Focus session timer with notifications
- Distraction counter
- End-of-day review (mood, insight logging)
- Early bird / night owl work templates

## Architecture
- MVVM with FocusEngine ObservableObject
- Local notification reminders
- JSON-based storage for budget and summaries

## Requirements
- iOS 17.0+
- Xcode 15.0+

## Philosophy
Based on the principle that 4 hours of deep, focused work per day is more productive than 8+ hours of distracted work.
